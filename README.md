# Projeto-Cloud-Ops
Gerenciamento e monitoramento básico de recursos na nuvem


## Objetivo
Desenvolver conhecimentos básicos sobre gerenciamento e monitoramento de recursos na nuvem utilizando Microsoft Azure.

## Ferramentas utilizadas
- **Microsoft Azure**
- **Azure CLI**
- **Linux**
- **Azure CLI**
- **Azure Monitor**
- **GitHub**
- **Markdown**

## Evidências

Os conteúdos desenvolvidos durante o projeto estão documentados nos arquivos Markdown deste repositório. O histórico de commits também registra as alterações realizadas ao longo do desenvolvimento.

## Atividades realizadas
- Estudo sobre computação em nuvem.
- Explicação sobre os fundamentos básicos em nuvem.
- Conhecimento sobre máquinas virtuais.
- Estudo de redes virtuais.
- Gerenciamento de recursos.
- Monitoramento e alertas.

## Aprendizados
- Entender os conceitos básicos de **Cloud OPS**.
- Compreender como usar os recursos responsável pelo gerenciamento do **Azure**.
- Praticar os comandos fundamentais do **Linux** e do **Azure**. 
- Entender como monitorar os recursos, como também os **alertas** do Azure.

## Próximos passos
Aprofundar mais ao fundo sobre os conhecimentos em Cloud Ops e infraestrutura.
